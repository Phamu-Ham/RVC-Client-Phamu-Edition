# RVC Client -Phamu's Edition-

> Windows向けの無料リアルタイムRVCクライアントです。RVC学習済みモデル（.pth）と対応するIndexファイル（.index・任意）を使い、マイクに入力した声をリアルタイムに変換できます。日本語UI、画像付きプリセット、モデルごとの設定保存に対応しています。

Phamu Studioが公開する、Retrieval-based-Voice-Conversion-WebUIを基にした非公式カスタム版です。このファイルは、AIがプロジェクトの目的、構成、機能、対応ファイル、導入経路を理解するためのMarkdown形式の参照資料です。BOOTHの商品紹介文とは別の文書です。

## プロジェクトの目的と範囲

- RVCによるマイク音声のリアルタイム変換を、日本語のデスクトップGUIで操作するプロジェクトです。名称にWebUIを含む元プロジェクトを基にしていますが、この配布版の操作画面はブラウザーではなくデスクトップアプリです。
- Phamu版の主な変更は、UI、プリセット管理、画像編集、テーマ、ウィンドウ操作、導入・問い合わせ支援です。既存の音声変換処理と同梱実行環境を維持しています。
- 利用者が用意したRVC学習済みモデルを使うクライアントであり、音声モデルそのものや、モデル学習サービスを提供するプロジェクトではありません。
- GUIはPython、PySimpleGUI、Tkinterを使用しています。音声変換にはPyTorch等の既存RVC構成を使用しています。

### 公開ソースと配布版の違い

Gitリポジトリには本体ソースと説明・配布関連ファイルを置いています。実行環境、共通重み、利用者の音声モデル・Index・個人設定は含みません。リポジトリのダウンロードやクローンだけで、配布版と同じ実行環境がそろうわけではありません。

通常の導入ではインストーラーがGitHub Releasesの分割ファイルを取得し、検証・結合・展開します。展開先は`RVC_Client_Phamu_Edition`で、`本体/`と「起動」「モデル（pth）を入れる」「Indexを入れる」のショートカットが入口になります。

## 使えるモデルとファイル

利用者がBOOTHなどで購入・入手したRVC用の学習済み音声モデルを追加できます。対応対象はRVC用のファイルであり、信頼できる配布元から用意することを前提としています。

| ファイル | 役割 | 必要性 |
| --- | --- | --- |
| `.pth` | RVCの学習済み音声モデル本体 | 必須 |
| `.index` | そのモデルに対応する特徴検索用の補助ファイル | 任意。モデルと一緒に配布されている場合などに併用できます |

- ボイスモデル・Index・個人用プリセット画像は、クライアントに同梱していません。
- `.index`だけでは音声変換できません。対応する`.pth`が必要です。
- `.pth`という拡張子だけで互換性が決まるわけではありません。他方式のAIモデルや学習途中のチェックポイントが、そのまま利用できるとは限りません。
- 別のモデルの`.index`を組み合わせず、モデル配布元の案内を確認してください。
- モデルの利用条件は配布元に従います。クライアントが無料であることと、モデルの利用許諾は別です。

## 主な機能

- 日本語の設定表示と説明。
- 「追加 ＋」画面への`.pth`／`.index`のドラッグ＆ドロップ、またはファイル選択。種類を自動で振り分け、本体内へのコピーとプリセット登録を行います。
- 画像付きプリセット一覧からのモデル選択と、モデルごとの設定保存。一覧はマウスホイールでも移動できます。
- プリセット画像の拡大・縮小、位置調整、クロップ。モデル画像と一覧アイコンの仕上がりを確認できます。
- 夜桜テーマとオレンジテーマのワンクリック切り替え。
- 音声デバイス、ボイスデザイン、エンジン設定の折りたたみ表示。
- 音声方式・入力・出力の選択欄でのホイール誤操作防止。閉じた欄ではページだけをスクロールし、一覧を開いて選択したときに設定を変更します（b1.1）。
- プリセットの右クリックから、モデル名（.pth）・Index名（.index）の変更とプリセット削除。
- 削除したプリセットをアプリ内のゴミ箱から30日間復元。元のモデル・Index・画像ファイルは削除しません。
- 起動・インストールのログ記録と、問い合わせ用ログZIPの保存。

## 導入手順

1. 上記の入手先から、配布インストーラーを取得します。BOOTHではZIPを解凍して中のBATを取り出します。GitHubではBATを直接取得できます。
2. インストールしたい、書き込み可能なフォルダにBATを置き、ダブルクリックします。GitやPythonの別途インストールは不要です。
3. BATと同じ場所に`RVC_Client_Phamu_Edition`フォルダが作成されます。その中の「起動」ショートカットを開きます。
4. プリセット一覧の左端にある「追加 ＋」を開き、RVCモデル（.pth）と対応するIndex（.index・任意）を選択またはドロップし、「追加」を押します。
5. 必要に応じて画像や設定を調整し、「プリセットを保存」で保存します。追加直後のPitchとIndexの強さは0です。
6. 入力にマイク、出力に目的の音声デバイスを選択し、「開始」を押します。

インストーラーは初回導入用です。既存のインストール先を上書きする自動アップデーターではありません。GitHubの「Source code」は開発用ソースであり、通常の利用ではBATから導入してください。

## 動作環境・導入時の目安

| 項目 | 内容 |
| --- | --- |
| OS | Windows 64bit |
| ダウンロード | 約3.61GB。取得時にインターネット接続が必要です |
| 空き容量 | 導入時は15GB程度を目安に確保してください |
| GPU | NVIDIA GPUでのリアルタイム変換を推奨。動作確認機はGeForce RTX 4070 Tiです |
| CPU | CPUでも起動できますが、リアルタイム動作の速度は保証していません |
| 同梱実行環境 | Python 3.9.13／PyTorch 2.0.0+cu118 |

GPU・ドライバー・モデル・設定によって動作状況、音質、遅延は異なります。すべての環境での動作・性能を保証するものではありません。元の音声変換処理を維持したカスタム版であり、独自の高音質化エンジンを追加した製品ではありません。

## よくある質問

### 購入した.pthと.indexを使えますか？

RVC対応の学習済みモデル（.pth）と、そのモデル用のIndex（.index）を追加できます。Indexは省略可能です。購入先の対応形式と利用条件を確認してください。

### 自分でモデルを学習させる必要がありますか？

利用できるRVC学習済みモデルがあれば、自分で学習する必要はありません。この配布版はリアルタイム音声変換用で、モデル学習機能は含みません。

### 入力した文章を読み上げるソフトですか？

このクライアントはマイクに入力した声を変換するソフトです。文章から音声を生成するTTSソフトではありません。

### DiscordやVRChatの通話に使えますか？

変換音声を通話アプリへ渡すには、必要に応じて仮想オーディオデバイスなどの音声ルーティングを別途設定します。[VB-CABLE](https://vb-audio.com/Cable/)を使い、本クライアントの出力を「CABLE Input」、通話アプリの入力を「CABLE Output」にする構成が一例です。仮想オーディオデバイスは同梱していません。

### 起動時に黒い画面が出ますが、待っていて大丈夫ですか？

起動直後は黒い画面に「起動中…」などの準備状況を表示します。初回の起動・変換には時間がかかることがあります。エラーが出る場合は、下記のログを確認してください。

β版の不具合、気になった点、追加してほしい機能は、[Phamu StudioのBOOTHショップ](https://phamu-studio.booth.pm/)のメッセージで受け付けています。

| 状況 | ログの確認・保存方法 |
| --- | --- |
| アプリを開ける | 「エンジン設定」→「問い合わせ用ログを保存」 |
| アプリを起動できない | インストール先の`本体/support_logs`を確認。代替保存先は「使い方」を参照 |
