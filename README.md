# RVC Client -Phamu's Edition- b1.0（β版）

日本語UIと画像付きプリセットで使える、無料のリアルタイムRVCクライアントです。

**[ダウンロード](https://github.com/Phamu-Ham/RVC-Client-Phamu-Edition/releases/download/b1.0/Install_RVC_Client.bat) · [BOOTHショップ](https://ham-shop.booth.pm/) · [詳しい使い方](app/使い方.txt)**

| 使う前に | 内容 |
| --- | --- |
| 対応OS | Windows 64bit |
| 容量 | ダウンロード 約3.64GB／導入時の空き容量 15GB程度 |
| 音声モデル | 信頼できる配布元の `.pth` を用意。対応する `.index` は任意 |
| 追加インストール | Git・Pythonは不要 |

## はじめる

| 手順 | やること |
| --- | --- |
| 1. ダウンロード | 上のリンクからBATファイルを保存 |
| 2. インストール | インストールしたい、書き込み可能なフォルダへBATを置いてダブルクリック |
| 3. 起動 | 同じ場所にできる `RVC_Client_Phamu_Edition` 内の「起動」を開く |
| 4. モデル追加 | 「追加 ＋」へモデル・Indexをドラッグ＆ドロップ、またはファイル選択 |
| 5. 変換開始 | 入力にマイク、出力に目的のデバイスを選んで「開始」 |

Discord・VRChatへ音声を渡す場合は、必要に応じて [VB-CABLE](https://vb-audio.com/Cable/) などを別途用意してください。仮想オーディオデバイスは同梱していません。

## できること

| 機能 | 内容 |
| --- | --- |
| プリセット | 画像で切り替え／モデルごとの設定保存 |
| 画像・テーマ | 拡大縮小・切り抜き／夜桜・オレンジの切り替え |
| 整理 | 右クリックでモデル名・Index名を変更／削除したプリセットを30日間復元 |
| 操作 | 設定の折りたたみ・開閉状態の保存／最大化・サイズ変更 |
| 問い合わせ | 起動・導入ログの記録／エンジン設定からログZIPを保存 |

プリセットを削除しても、モデル・Index・画像本体は残ります。

## 知っておくと安心

- **起動直後は黒い画面に「起動中…」と準備状況を表示します。** 準備中は閉じずにお待ちください。
- b1.0の配布ファイルを更新しました（2026-09-19）。以前のBATではなく、上のリンクから新しいBATを保存してください。
- 通信に失敗したら、同じBATを再実行できます。確認済みのダウンロードデータは再利用します。
- 既存フォルダは上書きしません。初回導入用で、自動アップデーターではありません。
- 導入後の一時データはゴミ箱へ移動します。空き容量が必要な場合は、内容を確認して整理してください。
- GitHubの「Source code」は開発用です。通常の導入には上のダウンロードリンクを使ってください。

動作確認：NVIDIA GeForce RTX 4070 Ti。GPU・ドライバー・設定によって動作状況は異なり、すべての環境での動作・性能を保証するものではありません。

## お問い合わせ

β版のため、気になる点・不具合・追加してほしい機能があれば、[Phamu StudioのBOOTHショップ](https://ham-shop.booth.pm/) のメッセージからお気軽にどうぞ！

| ログが必要なとき | 保存先・操作 |
| --- | --- |
| アプリが開く | エンジン設定 →「問い合わせ用ログを保存」 |
| 起動できない | `本体/support_logs`（保存できない場合の代替先は[使い方](app/使い方.txt)） |
| インストールできない | BATと同じ場所の `Phamu-Installer-Logs` |

ログの自動送信はありません。共有前に内容を確認し、不具合が起きた操作・時刻も添えてください。
