# RVC Client -Phamu's Edition- b1.0（β版）

日本語で使える、画像付きプリセット対応のリアルタイム RVC クライアントです。
Retrieval-based-Voice-Conversion-WebUI を基に、Phamu Studio が UI と操作性を調整したカスタム版です。元プロジェクトの公式版ではありません。

## ダウンロード・起動

1. [インストーラーをダウンロード](https://github.com/Phamu-Ham/RVC-Client-Phamu-Edition/releases/download/b1.0/Install_RVC_Client.bat)します。
2. 書き込み可能なローカルフォルダに保存し、ダブルクリックします。
3. 同じ場所にできる `RVC_Client_Phamu_Edition` 内の「起動」ショートカットを開きます。

Git・Python の追加インストールは不要です。初回は GitHub から約 3.64 GB をダウンロードします。結合・展開用に **15 GB 程度の空き容量**を用意してください。通信環境によって時間がかかります。

既存の同名フォルダは上書きしません。ダウンロード失敗時は同じバッチを再実行すると、検証済みの分割データを再利用します。成功後の一時データはゴミ箱へ移動します。容量を空ける際は、ゴミ箱の内容を確認してご自身で整理してください。

本インストーラーは初回導入用で、自動アップデーターではありません。初回起動後の設定・モデルを別の版で上書きしないでください。

起動時は黒いコマンド画面のまま準備に時間がかかる場合があります。アプリの画面が開くまで、そのままお待ちください。

**Releases の「Source code (zip)」はソース閲覧・開発用です。実行環境や共通重みを含まないため、通常の利用には上記のインストーラーを使ってください。**

## 主な機能

- 日本語の設定表示と説明ポップアップ
- 画像付きプリセット一覧・マウスホイールによる一覧移動
- 「追加 ＋」からモデルと Index をまとめてドラッグ＆ドロップ
- 画像の拡大縮小・クロップ、一覧への即時反映
- 折りたたみ式の設定、開閉状態の保存
- 夜桜・オレンジのワンクリックテーマ切り替え
- 変換中の状態表示、プリセットの保存・復元
- プリセットの右クリックからモデル名・Index 名の変更、プリセットの削除
- 削除したプリセット設定をアプリ内のゴミ箱から 30 日間復元（モデル・Index・画像本体は削除しません）
- ウィンドウの最大化・復元、画面上端へのドラッグによる最大化、四隅からのサイズ変更

## 音声モデルと通話設定

ボイスモデル（`.pth`）、対応する Index（`.index`）、個人用画像は含みません。信頼できる配布元のモデルを別途用意し、それぞれの利用条件に従ってください。

プリセット一覧の「追加 ＋」でモデルを登録し、入力にマイク、出力に目的の音声デバイスを選んで変換を開始します。
Discord・VRChat 等へ音声を渡す場合は、必要に応じて [VB-CABLE](https://vb-audio.com/Cable/) などを別途用意してください。仮想オーディオデバイスは同梱しません。

詳しい操作は [使い方](app/使い方.txt) を参照してください。

## 動作確認

- Windows x64 向け
- 確認 GPU: NVIDIA GeForce RTX 4070 Ti
- 同梱実行環境: Python 3.9.13 / PyTorch 2.0.0+cu118

既存の実行環境・音声変換処理を維持しています。GPU 世代・ドライバーによって動作状況が異なり、他の PC や GPU、CPU でのリアルタイム性能を保証するものではありません。
